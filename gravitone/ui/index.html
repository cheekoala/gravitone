These play as silence here, and the party runs on around them. Copy them over and they join in at their next turn.

    How it works

    The code carries the seed, the moment the party started and the gap settings — everything but the music itself. If the other machine holds exactly this playlist, the code is the whole handshake. If their library is bigger, or differs at all, hand over the party file once (next to the music you are sharing); after that the code alone works.

    In a party, skip sits a track out rather than moving the queue — the sound stops, your place does not, and you are back with everyone at the next track.

    Add music

    Add folder puts a whole folder in this playlist, played where it stands — anything you drop in there later joins by itself. Link files instead picks up the files that are there now, as symlinks. Either way nothing is copied.

      Settings

      Gaps
      Levels

      How long sound takes to arrive and to leave — including when you skip, so nothing is cut off mid-note. Off plays every track from its first sample.

      Playlists

      Each playlist has its own links, folders and removals. Switching one in changes what plays from the next track.

        Removed from this playlist

        Files in a source folder are never deleted — they are just kept out of this playlist.

          Folders in this playlist

          Played where they stand, nothing linked or copied. New files in them join the rotation by themselves.

            This playlist on disk

            Every linked track is a symlink in this folder, so the playlist is browsable in your own file manager as well as in here. A folder added whole plays in place and leaves nothing behind — Mirror as links lays those tracks out here too, without copying a byte or changing what plays.
